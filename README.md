# Rust Learning Journey

This repository documents my personal progress in learning Rust. I learn mostly by reading The Rust Programming Language book, and this repository is where I apply and practice what I learn from it. It is split into two parts:

## rustlings

This folder contains my work on [rustlings](https://github.com/rust-lang/rustlings), a set of community-created exercises designed to teach Rust through small, hands-on fixes and challenges. I use it to practice core language mechanics one concept at a time.

## projects

This folder is a playground of small, self-contained Rust programs rather than formal exercises. Each one is short, usually a single `main.rs`, and is built to demonstrate or explore one specific concept, for example:

- structs and impl blocks
- enums and pattern matching
- ownership and borrowing in practice
- other intermediate/advanced topics

I intentionally skip basic constructs such as loops, if statements, and functions in these projects, since that material is already covered thoroughly in rustlings. Instead, each project here focuses on a specific concept I want to understand better.

## Scope and approach

- This repository is a record of my own learning process, not a polished production codebase.
- Code quality and completeness will vary as I learn, and that is intentional: it reflects real progress over time rather than a finished product.
- Everything in this repository is written entirely by me. It is AI free: I do not use AI tools, AI assistance, or any other outside help to write, fix, or generate any code or content here. All mistakes, solutions, and progress are my own.
